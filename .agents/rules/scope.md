# Mục tiêu và phạm vi

Xây dựng trang quản trị SkyGo bằng React và UI Ant Design có sẵn, kết nối API SkyGo thật. Đọc cấu trúc frontend, package.json, layout, router và component hiện có trước khi sửa. Giữ UI, theme và quy ước dự án; tái sử dụng component thay vì viết lại toàn bộ. Trao đổi bằng tiếng Việt.

- Chỉ triển khai màn hình và thao tác thuộc phạm vi yêu cầu của người dùng.
- Không thay dữ liệu thật bằng mock để báo hoàn thành. Nếu backend chưa chạy hoặc thiếu thông tin kết nối, nêu rõ trạng thái.
- Không tự tạo API, trường JSON, trạng thái, ID hay chức năng mà backend chưa hỗ trợ.
- Không sửa backend, nới quyền hoặc bỏ OTP chỉ để frontend hoạt động.
